HOW TO VIEW
────────────
1. Open the zova/ folder in VS Code
2. Right-click index.html → "Open with Live Server"
   (Install "Live Server" extension if not installed)
   OR: Simply double-click index.html to open in your browser

HOW TO EDIT
────────────
→ Change brand name       : Search "ZOVA" in index.html & style.css
→ Change colors           : Edit :root variables in style.css
→ Change launch date      : Edit initCountdown() in js/main.js
→ Change products         : Edit product cards in index.html
→ Change prices           : Edit Rs. values in index.html
→ Add real images         : Replace files in images/ folder
→ Change fonts            : Edit Google Fonts link & --font-head/body in style.css
